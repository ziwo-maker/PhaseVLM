# 项目模块介绍和命令集成.md 修改说明

## 本次改动

- 新增高质量一阶段数据清洗命令
  - `--min_action_margin 1.0`
  - `--min_action_margin 1.5`
- 更新 Jinan 的 Stage 1 推荐命令
  - `lr` 调整为 `1.5e-4`
  - `warmup_ratio` 调整为 `0.1`
  - `temperature` 改为 `--temperature_sweep 0.05,0.07,0.1`
  - `prefix_tokens` 从 `16` 改为 `8`
- 新增高质量子集的 caption 回填与训练命令示例
- 文档中补充了说明
  - DDP 下 Stage 1 会自动使用全局 gather 的对比学习负样本池
  - train/val split 不再在切分前打乱样本
  - Stage 2 / Stage 3 的 `prefix_tokens` 需要和 Stage 1 对齐 checkpoint 保持一致
- 同步更新 Hangzhou 段落
  - 增加 `margin1.0` 清洗示例
  - Stage 1 和 Stage 2 的 `prefix_tokens` 调整为 `8`
  - Stage 1 参数同步更新为新的推荐配置

## 修改目的

- 让文档里的 Stage 1 命令与代码改动后的训练逻辑保持一致。
- 给出一版可直接复现的高质量子集方案，方便做 `margin` 过滤实验。
- 避免 Stage 1 和后续 Stage 2/3 在 `prefix_tokens` 上出现 checkpoint 不兼容。

## 建议使用顺序

1. 先生成 `align_train.cleaned.jsonl`
2. 再根据需要生成 `margin1.0` 或 `margin1.5` 子集
3. 对对应子集回填 `clip_caption`
4. 最后使用新的 Stage 1 命令训练
