# 研究方案：策略响应式反事实教师构造（PRCT）

**状态：** `REVISE`。机制与首个迁移结果充分，但尚缺第二个非饱和目标网络的独立复现。  
**唯一主创新：** 修复多路口反事实教师的协调语义；不新增学生模型或训练目标。

## Problem Anchor

PhaseVLM 的少样本仿真蒸馏在标签量增大时会损坏多路口闭环控制：传统 SimExpert 改变目标路口的候选相位，却冻结所有邻居在快照相位。该标签并不对应部署系统中邻居随策略重规划的响应，造成全直行偏置和高预算退化。目标是以最小改动构造与部署协调机制一致的反事实监督。

不研究新 VLM、通用 offline RL、主动选样或可靠性筛选；不将 generic advantage weighting 或 KL 先验宣称为创新。

## 方法论断

**PRCT 在同一 CityFlow 快照上固定一个目标路口的候选相位，同时让所有非目标路口在后续控制点按冻结 source policy 重新决策；120 秒全局 rollout 的四动作代价分布成为 Stage-3 教师。**

对状态 `s`、目标路口 `i` 和候选相位 `a`，PRCT 定义：

`c_PRCT(s,i,a; pi_b) = Sum_t g(x_t)`，其中 `u_i(0)=a`，非目标路口在每个 30 秒决策点采用 `u_j(t)=pi_b(h_j(t))`。`g` 为实现中统一的全局 ATT/AQL/AWT/spillback 代理成本。候选均从同一 snapshot 恢复，保留相同 yellow transition、Pareto/约束过滤与四动作归一化成本。

教师输出沿用 `candidate_action_waits`、`candidate_action_metrics` 和 `expert_action` schema。因此既有 Stage-3 mixed CE + soft target + ranking 损失与冻结 Qwen-VL 8B 均不变，测试时也不增加推理成本。

```text
source-policy snapshot
  -> force candidate action only at target i
  -> remaining intersections re-plan with frozen source policy
  -> 120s global counterfactual cost for each of four actions
  -> existing Stage-3 cost-distribution distillation
  -> standalone closed-loop student at inference
```

## 为什么是最小充分机制

问题在教师的干预语义，而不在学生容量或校准。冻结 H300、CRCD 多视界可靠性门均负向，且 PRCAT 的唯一有效 pilot 输给相同未加权教师。PRCT 只改变 rollout 中非目标路口的动作来源，不增加可训练参数、在线规划、记忆、奖励模型或额外数据源。

## 贡献边界

- **主张：** 在多路口 VLM traffic control 中，policy-responsive counterfactual teacher 比 frozen-neighbor teacher 更忠实于部署时的协调响应；该差别可以解释并消除已观测到的高预算 action collapse。
- **不主张：** 反事实信用分配首次用于 TSC、通用 policy improvement 保证、或任意流量/网络下都能改善 zero-shot policy。
- **PRCAT：** advantage weight 和 source-action KL 为已验证失败的可删除模块，保留为负向消融，不能写入标题、摘要或贡献列表。

## 已有证据

1. Jinan-to-Hangzhou 迁移中，冻结 c30 K=118 的 AWT 为 83.24，冻结 H300 为 236；responsive H120 K=118 的 9-training-seed 聚合为 `48.88 +- 2.76`，zero-shot 为 67.75，且优于 responsive H120 K=32 的 `57.93 +- 4.57`。高 K 的改善随教师响应语义变化而非简单随 K 增加。
2. Jinan real 的健康 pt8 source 上，responsive H120 K=118 报告为 `40.97 +- 0.84`，zero-shot 为 43.98，表明教师并不只适用于跨网迁移。
3. 同流 Jinan-2500、9 training seeds 中，responsive H120 K=118 为 `41.47 +- 0.98`，与 zero-shot 41.47 持平。该结果定义适用边界：当 source policy 在目标流已无可利用余量时，PRCT 不能凭空产生收益。
4. PRCAT full 的有效 pilot 为 `42.48 +- 0.22`，劣于同训练 seed 的未加权 PRCT `39.44`，故不得扩展为主方法。

## 可证伪预测

在 source policy 存在目标域余量的设置，PRCT H120 应在固定数据、预算、loss 和训练种子协议下，优于冻结邻居教师，并同时保持 action entropy、p95/max movement wait 和 spillback。若与同 horizon 的 frozen H120 相比没有 teacher-action/ranking 差异或在线收益，或在第二个非饱和目标网络复现失败，则“协调语义修复”只能作为诊断观察，不足以支撑方法论文。

## 风险控制

- 同一平均 AWT 的收益若以 tail wait、spillback 或相位多样性恶化为代价，判为失败。
- 所有主结果以独立**训练**种子聚合；CityFlow 评测种子不作为独立训练重复。
- 所有主臂先以内容 hash、快照清单、实际 K、source checkpoint 和 loss config 对账；Jinan-2500 的坏 snapshot 必须在选择前过滤。
- H120 为已验证的工作点而非理论最优；H30 和 H120 的配对对照用于区分视界长度与响应语义。

## 最小论文故事

一个教师构造改变、两条必要证据：

1. **机制：** frozen-neighbor 和 policy-responsive rollout 产生系统性的 label/ranking 与动作分布差异。
2. **结果：** 在两个有 headroom 的目标设置，PRCT H120 消除 frozen 高 K 退化且改善闭环安全指标；在饱和 Jinan-2500 上诚实报告零增益。
