# PRCT 补实验计划

**问题：** frozen-neighbor counterfactual 是否因违反部署中的多路口协调响应而生成有害教师标签？  
**方法论断：** PRCT 以固定目标动作、非目标路口按 source policy 重规划的 H120 rollout 构造四动作蒸馏教师。  
**日期：** 2026-08-18  
**原则：** 先验证因果识别和结果账本，再花预算扩展到第二网络；不继续优化 PRCAT。

## Claim Map

| Claim | 为什么重要 | 最低可信证据 | 关联块 |
|---|---|---|---|
| C1：PRCT 修复协调不一致的教师偏差 | 这是唯一主创新 | 同 horizon、同 snapshot、同 loss 下，响应式教师优于冻结教师并避免 action collapse | B1, B2 |
| C2：收益来自响应语义而非更长视界或更多标签 | 排除最直接替代解释 | frozen H120 vs responsive H120 的配对标签差异和闭环差异；H30 responsive 作为视界对照 | B1, B2 |
| C3：方法有边界而非 cherry-pick | 防止过度泛化 | Jinan-2500 饱和流复核为零增益；第二个有余量目标网络复现 C1 | B3, B4 |

**必须排除的反主张：** 增益只来自更长 rollout、K=118、mixed loss、某个训练种子，或用平均 AWT 掩盖相位/饥饿退化。

## 论文实验故事线

- **主文必须证明：** B1 的机制差异、B2 的九种子闭环配对主结果、B3 的独立网络确认。
- **主文必须报告：** B4 的 Jinan-2500 零收益边界和 PRCAT 负向删除结果。
- **附录：** H30 sensitivity、按交通强度/路口分层、完整行动频率、snapshot determinism、所有种子。
- **明确不做：** 扩展 PRCAT、更多 OOD selector、CRCD 新阈值搜索、没有 matched control 的多 loss 网格。

## Experiment Blocks

### B0：证据账本与可重复性预检

- **测试主张：** 现有 48.88、40.97、41.47 结果能被追溯，且各臂只在指定变量上不同。
- **数据/设置：** 读取每个原始 `aggregate.json` / `eval_summary.json`、标签 jsonl 和训练 config；Hangzhou 118 clean snapshots，Jinan-2500 116 clean snapshots。
- **比较：** 无模型比较；逐臂记录 `source_ckpt`、collection/test flow、clean snapshot IDs、actual K、horizon、teacher handler、loss、train/eval seed。
- **输出：** `prct_result_ledger.csv`、每数据文件 SHA256、可重生成的 mean/std/CI 脚本、缺失/冲突清单。
- **通过门：** 每个主文数值能追溯至九个独立 training seeds；“48.66”只能作为单 seed，聚合写作 `48.88+-2.76`。不通过则暂停所有新训练。
- **优先级：** MUST-RUN；约 0.25 GPU-hour，0.5 engineer-day。

### B1：同视界教师语义的配对标签审计

- **测试主张：** frozen 与 responsive 的差异来自 non-target response，而非 H120 本身。
- **数据/设置：** 对相同 120 个（过滤坏文件后实际 clean K）source-policy snapshots，在相同 `H=120`、global cost、transition、candidate set 和 source checkpoint 下分别生成 frozen-H120 与 responsive-H120 标签；重复一次验证字节级或容忍度内确定性。
- **比较：** frozen-H120、responsive-H120；仅作辅助的 frozen-c30、responsive-H30。
- **指标：** 每状态 expert-action disagreement；四动作 Spearman/Kendall rank correlation；winner margin；Pareto feasibility；全局 action frequency/entropy；按路口与 traffic-load 分层；teacher cost 与 3600s closed-loop delta 的相关。
- **关键图：** (1) action-disagreement heatmap，(2) frozen vs responsive action-frequency bar chart，(3) rank disagreement 对后续 tail wait 的散点/分位图。
- **通过门：** 证明 H120 下 handler 单独改变即导致可解释的 rank/action shift，且冻结分支的 through 偏置与较差的后续 tail 指标关联。若差异很小，停止“协调偏差”主张。
- **优先级：** MUST-RUN；预计 4-8 GPU-hours（先用 16 snapshots 校准，再扩到全量）。

### B2：锁定协议下的因果主实验

- **测试主张：** PRCT 消除 frozen teacher 的高 K 退化，且收益不是 loss 或随机种子造成。
- **数据/设置：** Jinan source -> Hangzhou target，disjoint collection/test flow，`K={32,118}`；固定 source checkpoint、clean snapshot pool、explicit snapshot-level split、mixed loss、epochs、checkpoint criterion和九个 training seeds `{2024,42,123,7,11,99,314,2718,9001}`。每 checkpoint 用三个固定 CityFlow eval seeds 汇总，不将它们计为独立样本。
- **比较系统：** zero-shot；frozen-c30（历史负对照）；**frozen-H120（关键匹配对照）**；responsive-H30；**responsive-H120/PRCT**。若 B0 验证既有 responsive-H120 完整且匹配，重用其九个 seed，仅补 frozen-H120；否则从头运行配对矩阵。
- **指标：** AWT 为预注册主指标；ATT、AQL；p95/max per-movement wait、spillback、action entropy/frequency；每 seed 的 paired Delta AWT；bootstrap 95% CI 或 paired permutation test（以 training seed 为单位）。
- **成功标准：** PRCT H120 对 frozen-H120 的 AWT 配对改善方向在至少 7/9 seeds 一致，双侧 95% CI 不跨零或预注册 permutation `p<0.05`；同时 p95/max wait、spillback 不恶化超过 5%，entropy 不向单相位塌缩。对 zero-shot 的优越性是次级确认。
- **失败解释：** 若 PRCT 只优于 c30 而不优于 frozen-H120，不能将收益归因给响应语义；若均值改善但 safety 失败，方法不成立。
- **表/图：** 主表 1（nine-seed mean+-std/CI）；图 2（paired seed slope）；图 3（行动频率和 tail wait）。
- **优先级：** MUST-RUN；预计 36-54 GPU-hours，分两阶段执行：先 3 seeds 发现问题，再补至 9 seeds确认。

### B3：第二个非饱和目标网络复现

- **测试主张：** PRCT 不是 Hangzhou 单例。
- **数据/设置：** 优先选择项目中已有 Stage-2 source checkpoint 且 zero-shot 有显著 headroom 的另一方向；候选优先级为 Hangzhou-to-Jinan，其次 NewYork 28x7。先在三个固定 eval seeds 上测 zero-shot、fixed-time 和强 rule/RL baseline，只有 zero-shot 明显低于可行参考且不存在饱和证据时才进入蒸馏。
- **比较：** zero-shot、frozen-H120、PRCT-H120（必须相同 K=118、loss、snapshot pool）；H30 只在 B1 显示视界混淆时加入。
- **指标与统计：** 同 B2，至少 5 training seeds 做 gate；通过后扩展至 9。报告 topology、intersection number、flow shift、实际 K 与 source performance。
- **成功标准：** PRCT 相对 frozen-H120 的 AWT 和至少一项安全指标同步改善，且五 seed 方向一致后才升级到九 seed。
- **失败解释：** 两个非饱和设置均不复现则降级为“教师偏差诊断”；单一复现成功可支持有条件的方法论文。
- **优先级：** MUST-RUN；预计 30-50 GPU-hours（以 B2 的单 seed计时实测校正）。

### B4：适用边界与删除检查

- **测试主张：** 论文不会将 zero-gain 饱和流误报为失败或泛化收益。
- **数据/设置：** 复核已完成的 Jinan-2500 collect=test、`K={32,118}`、九 seed 完整矩阵；审查实际 K=116、坏 snapshot 过滤和 exact zero-shot baseline。
- **比较：** zero-shot、frozen c30、responsive H30、PRCT H120；引用但不重跑 PRCAT full 的有效单-seed negative pilot。
- **通过门：** 结论保持“PRCT H120 K=118 与 zero-shot 持平，其他臂退化”，并将其解释为 headroom boundary；绝不挑选单个 seed 报告改善。
- **表/图：** 主文小表或 boundary panel；PRCAT 完整删除表放附录。
- **优先级：** MUST-RUN（分析，不新训）；约 0.5 engineer-day。

### B5：frontier 必要性检查

PRCT 的创新不在 LLM/VLM primitive，而在离线教师的干预语义。Qwen-VL 只作为冻结部署策略，故不强制新增 LLM 基线。公平性由“同一个 source policy、仅切换 non-target controller”而非替换基础模型保证。

## Run Order and Decision Gates

| 里程碑 | 目标 | 必跑内容 | Stop / Go 门 | 成本 |
|---|---|---|---|---|
| M0 | 审计账本 | B0 + 16 snapshots deterministic smoke | 数值、hash、schema 对齐才继续 | <1 GPUh |
| M1 | 识别教师差异 | B1 16 snapshots，随后全量 | 若 frozen-H120 与 PRCT 无可解释差异，停止 | 4-8 GPUh |
| M2 | 主因果结果 | B2 的 3 training seeds | PRCT 对 frozen-H120 无一致方向或 safety 失败，停止扩种子 | 12-18 GPUh |
| M3 | 统计确认 | B2 补齐至 9 seeds | CI / permutation 和 safety 均过门才跨网络 | 24-36 GPUh |
| M4 | 外部有效性 | B3 5 seeds，后续 9 seeds | 先证明 target 有余量；失败则降级叙事 | 30-50 GPUh |
| M5 | 完整写作 | B4 + appendix | 仅汇报已通过门的主张 | <1 GPUh |

## 计算与数据预算

- **总计：** 约 70-110 GPU-hours，取决于 B3 网络规模；每阶段先以单 GPU/三 seed的实际时长校准，不预先并行超过空闲 GPU 数。
- **数据：** 仅已有 CityFlow snapshots 和 flows；每次收集前检查 snapshot JSON 完整性，记录 clean IDs 和实际 K。
- **主要瓶颈：** policy-responsive label rollout，而非 VLM finetuning；B1 可提前暴露是否值得训练矩阵。

## 风险与缓解

- **指标代理错配：** teacher selection 不作结论，独立 3600s online metrics 裁决。
- **种子/切分混淆：** 固定 snapshot selection，paired training-seed comparison；仅 training seed 进入统计。
- **饱和目标误判：** 先运行 headroom gate，Jinan-2500 只作边界。
- **H120 post hoc：** H30 与 frozen-H120 控制；不搜索多个 horizon 直到显著。
- **坏快照或非确定性：** B0 hash 与 B1 replay 审计，失败即暂停。
